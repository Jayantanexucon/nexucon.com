# RAID Register: Risks, Assumptions, Issues, and Dependencies

**Document Reference:** NEX-RAID-REG-v1.0  
**Project:** Nexucon Company Website & Marketing CMS Platform  
**Target Release:** Production Launch  
**Governance:** Architecture Review Board (ARB)  

---

## 1. Risks Register (R)

| Risk ID | Risk Description | Severity | Likelihood | Impact | Mitigation Strategy | Owner | Target Milestone | Status |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **R-01** | **Strapi Community Edition RBAC Limits:** Strapi Community Edition restricts role-based access control to 3 pre-defined roles. If marketing demands complex editorial hierarchies (Author -> Reviewer -> Legal Approver -> Publisher), native workflow features will be blocked. | High | High | Editorial bottlenecks or premature license costs. | Standardize initial editorial governance into 3 pragmatic roles: Author (Draft only), Editor (Draft & Publish), Admin (Configuration). Use Next.js Draft Mode preview tokens for external reviews. Upgrade to Strapi Enterprise if 4+ roles become mandatory. | Head of Marketing & Solution Architect | Release 1 | OPEN |
| **R-02** | **Unconfirmed ATS Interface Contracts:** Integration specifications for the external ATS / Staff Augmentation Portal are pending formal verification with the ATS engineering team. Incompatible schemas could delay candidate ingestion. | High | Medium | Application form failure or delayed Careers launch. | Define a strict JSON interface contract (`NEX-ATS-CONTRACT-v1.0`) in the SRS. Build a mock ATS gateway adapter in the Next.js API layer to allow end-to-end frontend development and testing prior to third-party connectivity. | Lead Developer & ATS Owner | Release 2 | OPEN |
| **R-03** | **CRM Outage / API Rate Limiting:** High-volume marketing campaigns or transient downtime in the corporate Lead Management / CRM Portal could cause dropped leads or timeouts during form submission. | High | Medium | Loss of high-value prospective enterprise consulting clients. | Implement the Transactional Outbox pattern: write all submissions to an encrypted PostgreSQL queue table with status `PENDING` before dispatching to the CRM. A background worker retries failed dispatches up to 5 times with exponential backoff. | Backend Lead | Release 2 | OPEN |
| **R-04** | **Organic Search Ranking Drop during Cutover:** Migrating from legacy URLs (including historic `.php` and `.html` paths) without complete 301 redirect parity could cause severe Google PageRank loss and organic traffic decay. | Critical | Medium | Substantial loss of organic inbound traffic and brand visibility. | Crawl the legacy site comprehensively using Screaming Frog. Implement a strict redirect table in Next.js `middleware.ts` for 1:1 legacy preservation. Conduct staging URL regression testing before DNS switch. | SEO Specialist | Release 3 | OPEN |
| **R-05** | **SVG File Upload Cross-Site Scripting (XSS):** Allowing raw SVG uploads in the media manager creates a high-severity stored XSS vector if malicious `<script>` tags are embedded within vector markup. | Critical | High | Compromise of administrator sessions and defacement of the public web application. | Enforce server-side XML parsing and sanitization (via DOMPurify or equivalent XML sanitizer) on all uploaded SVG files. Strip all `<script>`, `onload`, and external xlink attributes before writing to Azure Blob Storage. | Security Architect | Release 1 | OPEN |
| **R-06** | **Candidate PII Exposure via Insecure Resume URLs:** Storing resumes in public storage or returning permanent URLs would expose candidate personal data (contact info, work history) to public scraping or indexing. | Critical | Low | Severe GDPR / SOC 2 compliance violation and reputational damage. | Resumes are strictly stored in a private Azure Blob container (`resumes-private`) with public access disabled. Recruiter downloads are mediated exclusively via time-limited (15-minute) Azure Shared Access Signature (SAS) tokens generated on demand. | Security Architect | Release 2 | OPEN |
| **R-07** | **Gemini AI Hallucination of Business Claims:** Unsupervised AI generation of website copy could invent fictitious SAP certifications, exaggerated case study metrics, or non-existent partnerships. | High | Medium | Legal liability, loss of enterprise client trust, and compliance breaches. | Enforce a strict "Human-in-the-Loop" policy. The Gemini API is restricted to server-side assistance for draft metadata, keyword extraction, and FAQ structure. Content cannot be automatically published without explicit Editor approval. | Head of Marketing & AI Lead | Release 3 | OPEN |
| **R-08** | **Azure App Service Resource Contention on Shared Plan:** Hosting both the Next.js SSR frontend and the Strapi 5 Node.js admin portal on a single B1/B2 App Service Plan could cause memory exhaustion during content rebuilds or traffic spikes. | High | Medium | Sluggish page response times, 503 service unavailable errors. | Separate Next.js and Strapi into distinct App Service instances under the same App Service Plan initially. Monitor CPU/RAM in Application Insights. Auto-scale or isolate Strapi onto a separate plan if memory utilization exceeds 80%. | DevOps Lead | Release 1 | OPEN |
| **R-09** | **Bot-Driven Form Spam & Resource Depletion:** Public contact and application endpoints without protection could be flooded by automated bot submissions, corrupting CRM lead data and exhausting storage quotas. | High | High | Sales team fatigue, corrupted analytics, degraded API throughput. | Integrate Cloudflare Turnstile bot verification on all public forms. Implement IP-based and session-based rate limiting on `/api/leads` and `/api/careers/apply` via Next.js middleware and Edge headers. | Security Architect | Release 2 | OPEN |
| **R-10** | **Media Storage Cost Inflation:** Unchecked image uploads of excessive dimensions (e.g., 20MB raw PNGs) could bloat Azure Blob Storage costs and degrade Core Web Vitals (LCP). | Medium | Medium | Slow page load, poor user experience, ballooning cloud bills. | Enforce an 8MB upload ceiling. Strapi media pipeline auto-generates responsive WebP/AVIF variants (thumbnail, small, medium, large). Public images are cached at the edge via Azure CDN / Cloudflare with long `max-age` headers. | Full-Stack Lead | Release 1 | OPEN |
| **R-11** | **Database Connection Exhaustion from Serverless Edge:** Next.js Route Handlers and Server Actions executing concurrently could overwhelm PostgreSQL Flexible Server connection limits if PgBouncer is omitted. | High | Medium | Intermittent HTTP 500 errors on dynamic pages and form endpoints. | Enable built-in PgBouncer connection pooling on Azure Database for PostgreSQL Flexible Server. Configure connection pool limits in Prisma/TypeORM/Strapi to max 10 connections per container instance. | Database Administrator | Release 0 | OPEN |
| **R-12** | **Staging Environment Accidental Search Indexing:** If staging or UAT environments are crawled by Googlebot, duplicate content penalties will be assessed against the production domain. | High | Medium | Production SEO dilution and cannibalization in SERPs. | Hardcode `X-Robots-Tag: noindex, nofollow` in Next.js middleware for all non-production hostnames (`*.azurewebsites.net`, `staging.nexucon.com`). Enforce HTTP Basic Authentication or Entra ID protection on pre-production environments. | SEO Specialist | Release 0 | OPEN |
| **R-13** | **Unvalidated Rich-Text Content Injection:** Marketing editors pasting raw HTML code into Strapi dynamic zones could inadvertently break Next.js page layouts or inject broken styles. | Medium | Medium | Visual layout breakage and broken user experience. | Replace raw HTML fields with structured Strapi Blocks (rich text based on JSON AST) or Markdown parsed by a strict React renderer with custom design-system component mappings. | Frontend Lead | Release 1 | OPEN |
| **R-14** | **Cold Start Latency on Azure App Service Linux:** Linux App Service containers can experience cold start delays (5–15 seconds) after periods of inactivity or scale-out events. | Medium | Medium | Frustrating first-time editor experience or slow webhook execution. | Enable "Always On" feature on the Azure App Service Plan. Configure automated synthetic availability pings in Application Insights every 5 minutes to keep runtimes warm. | DevOps Lead | Release 0 | OPEN |
| **R-15** | **Absence of Enterprise WAF at Launch:** Relying on Cloudflare Free/Pro rather than enterprise Azure WAF leaves sophisticated layer-7 zero-day exploits dependent on application-level hardening. | Medium | Low | Potential vulnerability if code-level sanitization is bypassed. | Enforce strict security headers (Content Security Policy, HSTS, X-Content-Type-Options, Permissions-Policy) in Next.js configuration. Plan upgrade to Cloudflare Business / Enterprise or Azure WAF when revenue justifies the cost. | Security Architect | Release 3 | OPEN |

## 2. Assumptions Register (A)

| Assumption ID | Assumption Description | Validation Strategy | Impact if Invalid |
| :--- | :--- | :--- | :--- |
| **A-01** | The existing ATS / Staff Augmentation Portal provides a modern REST API supporting HTTPS and token-based authentication (Bearer token or API Key). | Direct review of ATS API documentation with ATS engineering team during Release 1. | An intermediate custom integration middleware or CSV batch process will need to be developed. |
| **A-02** | The corporate Lead Management / CRM Portal can accept incoming lead payloads via HTTPS REST POST and respond within 3,000ms. | Execute test HTTP payloads against CRM sandbox endpoint in Release 1. | Asynchronous webhook or queue ingestion must be prioritized earlier in the project lifecycle. |
| **A-03** | Nexucon possesses an active Microsoft Entra ID (Azure AD) tenant capable of registering application credentials for Single Sign-On (SSO). | Coordinate with corporate IT administration to verify tenant admin consent in Release 0. | Internal staff must rely on native database credentials with enforced MFA plugins. |
| **A-04** | Cloudflare is authorized by IT leadership to act as the primary DNS authority and edge proxy for `nexucon.com`. | Review domain registrar access and DNS delegation permissions in Release 0. | Azure DNS and Azure CDN / Front Door must be substituted, increasing baseline infrastructure costs. |
| **A-05** | The Digital Marketing team will produce and approve all core service copy, case studies, and blog content prior to Release 3 (UAT). | Weekly editorial sprint reviews tracked against the content migration spreadsheet. | Production launch will need to be phased with placeholder landing pages or launch delayed. |
| **A-06** | Azure subscription spending limits and resource group creation rights are provisioned with sufficient quota for App Service and PostgreSQL Flexible Server. | Execute Bicep dry-run deployment in development subscription in Release 0. | Deployment blocked until subscription administrator grants Contributor RBAC role. |
| **A-07** | A single production geographic region (Azure UK South or North Europe) is sufficient for initial launch traffic and data residency compliance. | Review client NDAs and GDPR compliance mandates with legal counsel. | Multi-region active-passive topology required, doubling infrastructure expenditure. |
| **A-08** | Google Gemini API quotas (Tier 1 pay-as-you-go) are sufficient to handle server-side marketing assistance workflows without hitting rate limits. | Configure budget caps and monitor token consumption in Google Cloud Console. | Implement local Redis caching for prompt completions or fall back to rule-based SEO templates. |
| **A-09** | Resumes submitted by candidates will strictly adhere to standard formats (PDF, DOC, DOCX) and not exceed 5MB in file size. | Client-side and server-side file type and size enforcement. | Ingestion pipeline will reject oversized portfolios; candidates must be directed to provide external portfolio links. |
| **A-10** | The initial monthly cloud infrastructure budget ceiling is strictly set to \$350 USD per month during the first 6 months of operations. | FinOps monitoring via Azure Cost Management alerts set at \$250, \$300, and \$350 thresholds. | Higher-tier resources (AKS, Front Door, APIM) must remain strictly excluded until approved. |

## 3. Issues Register (I - As-Is Codebase Findings)

| Issue ID | Discovered Issue in Repository | Evidence in Codebase | Risk & Business Impact | Resolution in Target Architecture |
| :--- | :--- | :--- | :--- | :--- |
| **I-01** | **Hardcoded Plaintext Credentials Displayed in UI:** The login interface explicitly displays default administrative credentials to all users. | `app/login/page.tsx` line 121: `"Default admin: admin@nexucon.com / Admin@123"` | Catastrophic unauthorized administrative access if deployed publicly. | Remove hardcoded credentials entirely. Decommission custom login route in favor of Strapi Admin and Entra ID SSO. |
| **I-02** | **Ephemeral Local Disk Storage for Uploads:** Media files are written directly to local server filesystem, which does not persist across cloud instances. | `app/api/upload/route.ts` line 31: `path.join(process.cwd(), "public", "uploads")` | Files will vanish upon any App Service restart, deployment, or auto-scaling event. | Replace local file system with Azure Blob Storage via `@strapi/provider-upload-azure-storage` for CMS assets and private Blob SDK for resumes. |
| **I-03** | **Contact Form Lacks Bot Defense & CRM Dispatch:** Contact submissions write only to local MongoDB/memory store with no spam filtering or CRM sync. | `app/contact/page.tsx` lines 11–15 & `app/api/enquiries/route.ts` | Form is vulnerable to spam flooding; marketing leads never reach the sales team. | Rewrite contact action to validate Cloudflare Turnstile token and forward enriched payload to corporate CRM gateway. |
| **I-04** | **Unsanitized Dynamic Catch-All Route Rendering:** Catch-all content page renders plain text and unchecked schema JSON directly into DOM. | `app/content/[...slug]/page.tsx` line 55: `dangerouslySetInnerHTML={{ __html: JSON.stringify(schema) }}` | Potential XSS or invalid JSON-LD breaking search engine structured data parsers. | Implement strict JSON schema parsing and sanitize all rich-text content using standard React markdown/AST renderers. |
| **I-05** | **Missing Dynamic Sitemap & Robots Endpoints:** No `sitemap.ts` or `robots.ts` exists in the Next.js App Router tree. | Verified absence of `app/sitemap.ts` and `app/robots.ts` in workspace. | Search engine crawlers cannot discover newly published pages or respect crawl budgets. | Implement dynamic `app/sitemap.ts` and `app/robots.ts` querying Strapi published routes with 24-hour ISR revalidation. |
| **I-06** | **Database Failure Silently Masked by Memory Fallback:** When MongoDB connection drops, code reverts to transient in-memory arrays without alerting. | `lib/store.ts` lines 90–105 & `lib/db.ts` line 50: `cached.unavailableUntil = Date.now() + 15000` | Data entered during database outages is permanently lost upon server container recycle. | Eliminate in-memory fallback. Enforce strict PostgreSQL connection pooling with health check probes and Application Insights alerts. |
| **I-07** | **Legacy PHP Relic Code Stored in CMS Settings:** The default site settings contain obsolete WordPress/PHP header code snippets. | `lib/store.ts` line 42: `"<!-- Example header.php code -->\n<?php echo get_header(); ?>"` | Clutters configuration with dead code and confuses content editors. | Purge all legacy PHP variables during Strapi PostgreSQL data seeding. |
| **I-08** | **Zero Careers Functionality in Baseline:** No job listings, job detail pages, candidate application schemas, or resume upload routes currently exist. | Full repository scan confirms total absence of recruitment modules. | Complete Careers subsystem must be designed and built from the ground up in the target platform. | Implement dedicated Careers route groups (`app/(careers)/*`) and API endpoints specified in the SRS. |
